# 上游贡献包使用指引

本目录包含两份可提交的上游材料：QEMU 上游 issue 草稿 + reims-vgpu
Windows 移植补丁集。所有材料已就绪，提交动作需要你的账号权限。

## A. QEMU 上游 issue（Bug B 证据包）

**文件**：`contrib/qemu-issue-bugB.md`（正文）+ `contrib/evidence/registers.md`
（寄存器证据）

**提交步骤**：
1. 登录 gitlab.com（QEMU 官方仓库：https://gitlab.com/qemu-project/qemu/-/issues）；
2. New issue → Bug → 粘贴 issue 草稿全文；
3. 把 `registers.md` 内容作为附件/评论贴入；
4. 可附加我们的诊断补丁 `contrib/qemu-whpx-timer-cpuid.patch`（它演示了
   CPUID 过滤行为，issue 里已引用）。

## B. reims-vgpu Windows 移植 PR（你的 fork → steelbrain/reims-vgpu）

**文件**：`contrib/reims-windows-port/`（0001-0004 + boot-windows.sh 属于
reims-vgpu；0005-0006 属于 qemu 子模块仓库）

**提交步骤**：
1. 把 0001-0004 依次 `git apply` 到 fork 的 Windows 分支，boot-windows.sh
   直接加入（注意：它在 .gitignore 里，需 `git add -f`）；
2. 0005-0006 需要推到 **qemu-reims-vgpu 的 fork**（steelbrain/qemu-reims-vgpu
   是子模块上游）——你可以再 fork 一个 qemu-reims-vgpu，或直接在本仓库 PR
   里附上这两枚补丁请求 steelbrain 帮忙合入；
3. push 分支 → 打开 PR → 粘贴 `README-PR.md` 作为 PR 描述；
4. 按上游 AGENTS.md 的门槛准备被 review：这些是平台移植改动，review 重点
   会是"行为是否与 Linux 臂同构"（0002/0003 是与既有臂同构的最小改动）。

## C. 注意事项

- `qemu-whpx-timer-cpuid.patch` 是手写补丁（隔离自混有上游补丁的
  whpx-all.c 工作树），可直接 `git apply` 或贴到 issue；
- 上游 whpx 的 4 枚补丁（xsaves/FP/PAT/hypercall）**不需要提交**——它们已在
  QEMU 上游 master；
- issue 里没有点名 macOS 许可问题，只描述"x86_64 客户机内核"的技术事实；
- 如果你想让我在某个提交步骤上继续帮忙（比如把补丁整理成 git send-email
  格式），回来告诉我。


## D. 路线判断：上游 PR vs 独立仓库（决策记录）

**结论：双轨制。** 干净的平台移植补丁（0001-0006 + boot-windows.sh）提上游
PR——理由：项目节奏快（本地私藏补丁会被上游重构撕烂）、代码明确为 Windows
端口留缝、补丁是平台门控的最小改动、合入后由上游维护、提交积累社区信用。
研究/运维资产（docs、evidence、runbooks、MSYS2 环境 hack、实验补丁如
whpx timer-CPUID）放独立仓库——理由：上游的验证门槛（conformance + 真机
live-boot）在 Windows-only 硬件上跑不全，实验内容不适合作为产品代码提交。
独立仓的形态：补丁文件 vs pinned rev（不养长期代码 fork），本工作区
docs/ + contrib/ 即其雏形。顺序：先 PR → 并行建仓与提 issue → 若上游搁置
Windows 补丁，补丁文件随时可升级为长期 fork 线。


## E. 两个上游的澄清（为什么有 GitLab）

Bug B 属于 QEMU 的 whpx 后端，不属于 reims-vgpu——隔离证据：不挂 reims
设备（vmware-svga 控制台）XNU 在 WHPX 下同样崩溃。QEMU 官方项目自 2021 年
起 issue/MR 托管在 GitLab（gitlab.com/qemu-project/qemu，补丁走 qemu-devel
邮件列表）；reims-vgpu 及其 QEMU 分支（steelbrain/qemu-reims-vgpu）在
GitHub。提交落点矩阵：

| 材料 | 目标 | 平台 |
|---|---|---|
| Windows 移植补丁 0001-0006 + boot-windows.sh | steelbrain/reims-vgpu（0005-0006 关联 qemu-reims-vgpu） | GitHub PR |
| Bug B 证据 + 修复追踪 | gitlab.com/qemu-project/qemu | GitLab issue |
| （可选）whpx 修复先行版 | steelbrain/qemu-reims-vgpu | GitHub PR |
